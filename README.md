# homebrew-tap

Homebrew tap for [@ciscoriordan](https://github.com/ciscoriordan)'s command-line tools.

## Formulae

| Formula | Description |
| --- | --- |
| [`storescreens`](Formula/storescreens.rb) | Simulator setup, XCUITest orchestration, and raw screenshot collection |

StoreScreens version 4 handles simulator setup, XCUITest orchestration, and raw screenshot collection. Use your preferred screenshot renderer and App Store Connect command-line tool. We recommend [Koubou](https://github.com/bitomule/Koubou) for screenshot composition and rendering, and [ASC CLI](https://asccli.sh/) for App Store Connect management and uploads. Neither is required for capture; the former Wall of Apps functionality is removed.

```sh
brew install ciscoriordan/tap/storescreens
```

mise and curl installation commands are also available in the [StoreScreens installation instructions](https://github.com/ciscoriordan/storescreens-cli#install). Version 4 configuration differs from version 3; read the migration guide before updating an existing workflow.

The formula is generated by the CLI repository's `scripts/update-homebrew.py` from its version file and release archive. It installs the XCUITest template resource bundle beside the binaries.
