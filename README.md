# homebrew-tap

Homebrew tap for [@ciscoriordan](https://github.com/ciscoriordan)'s command-line tools.

## Formulae

| Formula | Description |
| --- | --- |
| [`storescreens`](Formula/storescreens.rb) | Simulator setup, XCUITest orchestration, and raw screenshot collection |

StoreScreens is active again with a focused capture workflow in version 4. We recommend [Koubou](https://github.com/bitomule/Koubou) for screenshot composition and rendering, and [ASC CLI](https://asccli.sh/) for App Store Connect management and uploads.

```sh
brew install ciscoriordan/tap/storescreens
```

On Macs using mise, follow the [StoreScreens installation instructions](https://github.com/ciscoriordan/storescreens-cli#install). Version 4 configuration differs from version 3; read the migration guide before updating an existing workflow.

The formula is generated by the CLI repository's `scripts/update-homebrew.py` from its version file and release archive. It installs the XCUITest template resource bundle beside the binaries.
